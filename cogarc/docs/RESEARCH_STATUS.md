## What this release does and does not demonstrate
The V7 browser console is an interactive prototype. The repository does not contain an independently verified training pipeline, public-dataset evaluation results, a completed graph-attention experiment, or a completed human-subject study.

The WESAD / CASE / DEAP evaluation sequence and graph-attention approach are **planned research methods**. Any future experimental claims should be supported by versioned code, data provenance, evaluation protocols, and reproducible results.
