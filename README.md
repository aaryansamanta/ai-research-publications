## 🧭 Behind the builds

| Research practice | What the portfolio shows |
|---|---|
| **Reproducibility** | Project-level source repositories, technical notes, and available notebooks |
| **Scientific care** | Distinction between implemented systems, preliminary analyses, and future experiments |
| **Collaboration** | Team and mentor contributions identified rather than presented as solo work |
| **Real-world use** | AI Ethos and NextGenAI connect software projects with education and community initiatives |

### Research notes & attribution

- **IEEE AIAM:** The accessible software demonstration features XGBoost/SHAP; the GA–GNN research-paper methodology should not be mistaken for a verified end-to-end implementation in the linked code.
- **UCLA COSMOS:** InfernoTactics was developed as part of a five-student team. **UCSB:** The *C. elegans* project involved research collaborators and mentors.
- **CogArc:** The interactive browser prototype is implemented; graph-attention validation and wearable/EEG experiments are planned, not completed.
- **Stanford Urology:** Mentored analysis uses existing clinical measurements; identifiable patient data are not included here.
- **AI Ethos / NextGenAI:** Website and repository links are provided. Specific personal coding contributions should be identified in their respective READMEs.
- **Competition placements:** Rankings are reproduced from the provided project list and should be checked against official competition records.
