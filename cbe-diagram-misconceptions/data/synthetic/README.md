# Synthetic Pilot Data — Placeholder Only

`synthetic_pilot_data.csv` is **fabricated data**, generated by `generate_synthetic_data.py`, that mimics the shape of what Phase 2/3 data collection is expected to produce (per-student misconception flags, pre/post scores, confidence ratings, split by `group` = standard vs. enriched diagram, and `topic`).

**Purpose:** let the analysis pipeline in `/analysis` be written and tested end-to-end before real classroom data exists — so that once real data is collected, only the CSV needs to be swapped in.

**Do not** use this data, or any results derived from it, in the manuscript, in any report, or as evidence of the hypothesis. It is a structural stand-in only.

## Columns

| Column | Type | Description |
|---|---|---|
| `student_id` | int | Synthetic participant ID |
| `cohort` | str | `high_school` or `college` |
| `group` | str | `standard` or `enriched` diagram condition |
| `topic` | str | `cell_structure`, `central_dogma`, or `life_cycle` |
| `misconception_pre` | 0/1 | Target misconception present at pre-test |
| `misconception_post` | 0/1 | Target misconception present at post-test |
| `pretest_score` | float 0–1 | Concept score, pre-test |
| `posttest_score` | float 0–1 | Concept score, post-test |
| `confidence_rating` | int 1–5 | Self-reported confidence |

Regenerate with a different `random.seed(...)` or `N_PER_GROUP` in `generate_synthetic_data.py` to stress-test the analysis script under different sample sizes/effect sizes.
